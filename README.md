# P3 — Smart Time Planner

## Overview

**Smart Time Planner** is a web application designed to help users organize their time, plan their daily activities, manage tasks, and track their weekly progress.

The application provides a dashboard that gives an overview of the user's current schedule, available free time, completed tasks, study time, work time, sport activities, and other personal activities.

## Live Application

https://planencyberwork.vercel.app/

## Main Features

- **Dashboard** — Overview of the current day and its progress.
- **Calendar** — Organize and manage scheduled activities.
- **To-Do** — Manage daily tasks and track completed tasks.
- **Settings** — Manage application settings.
- **Free Time** — Display available free time during the day.
- **Time Tracking** — Track time spent on different activities.
- **Weekly Progress** — Monitor weekly progress for activities such as:
  - Work
  - Cybersecurity
  - Sport
  - French
- **Daily Timeline** — Visualize activities throughout the day.
- **Cybersecurity Study** — Track and organize cybersecurity study sessions.

## Purpose

The main purpose of this application is to improve time management by helping the user:

- Plan the day.
- Organize activities.
- Manage tasks.
- Track study and work time.
- Monitor weekly progress.
- Identify available free time.
- Maintain a structured daily routine.
